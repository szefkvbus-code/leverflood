# Lever Flood (Fabric 1.21.4)

Right-click a lever while holding a block: the lever is flooded away and your
block is placed in its spot, all in one tick.

## Get the jar without installing anything
1. Create a free GitHub account and a new empty repository.
2. Upload everything from this folder (including the hidden .github folder).
3. Open the "Actions" tab, wait for the "build" run to finish (about 2-3 min).
4. Open the run, download "leverflood-jar" at the bottom, unzip it.
5. Put leverflood-1.0.0.jar in your mods folder next to Fabric API 0.119.4+1.21.4.
